# Movies Reviews - Frontend

Interfaz web de la aplicación Movies Reviews.

## Tecnologías
- React
- Vite
- React Router

## Funcionalidades
- Registro e inicio de sesión.
- Visualización de películas.
- Publicación y consulta de reseñas.
- Acceso según autenticación y permisos de usuario.

## Instalación

1. Instalar las dependencias:
npm install

2. Crear el archivo .env y configurar la URL del backend:
VITE_API_URL=http://localhost:3000

3. Iniciar la aplicación:
npm run dev
